# Persian brand copy

## When to use it

Write or revise a Persian heading, CTA, campaign, product description or interface message. Supply the action, audience, channel, facts and voice examples. A small edit stays a small edit.

## Request and synthetic example

```text
با $persian-brand-copy دو نسخهٔ رسمی و محاوره‌ای بنویس.
ثبت درخواست تعمیر رایگان است؛ بعد از بررسی برآورد هزینه می‌دهیم.
زمان مراجعه و موجودی تعمیرکار مشخص نیست. CTA فرم درخواست را باز می‌کند.
```

Original illustrative drafts:

- Formal: «درخواست تعمیر ثبت کنید و برآورد هزینه بگیرید»
- Conversational: «درخواستت رو ثبت کن تا برآورد هزینه بگیری»
- Supporting line: «ثبت درخواست رایگان است؛ هزینهٔ تعمیر پس از بررسی برآورد می‌شود.»
- CTA: «ثبت درخواست»

Both voices preserve the same offer. Neither promises a free repair, cheapest price or guaranteed appointment. These lines have not been measured for conversion.

## It is working if

Copy fits the requested placement/register and every promise matches supplied facts. Unknown critical terms are visible or omitted. Alternatives change voice rather than offer meaning.

## Common limits

Orthography does not determine brand voice. Supplied colloquial style should not be flattened into formal language. Scarcity, deadlines and guarantees require actual facts. Drafting does not authorize publication.
