# قواعد کاربردی برای محصول ایرانی

این نقشه، جزئیات مرتبط با ایران را به اسکیل مسئول وصل می‌کند. همهٔ موضوع‌ها برای هر پروژه لازم نیستند؛ زبان فارسی، محل زندگی و قرارداد عملیاتی محصول را جدا مشخص کنید. مثال‌ها ساختگی‌اند و اثر روی کاربر واقعی اندازه‌گیری نشده است.

| موضوع | قاعده و ورودی لازم | اسکیل مرتبط |
|---|---|---|
| ریال و تومان | در قرارداد رایج این مثال، ۱ تومان = ۱۰ ریال؛ ۲٬۵۰۰٬۰۰۰ ریال = ۲۵۰٬۰۰۰ تومان. واحد ذخیره، نمایش و درگاه مشخص و تبدیل فقط یک‌بار انجام شود. | رابط، متن، مقایسه، پژوهش، سئو |
| مبلغ نهایی | کالا + ارسال + هزینه‌های اعلام‌شده − تخفیف؛ ارسال نامعلوم صفر نیست. | رابط، متن، مقایسه، پژوهش |
| وضعیت پرداخت | موفق، ناموفق، لغوشده و نامشخص از پاسخ معتبر محصول؛ برگشت از درگاه کافی نیست. | رابط، متن، مقایسه |
| کسر وجه و پیگیری | مهلت و مقصد بازگشت از سیاست همان ارائه‌دهنده؛ ۷۲ ساعت قانون همهٔ پرداخت‌ها نیست. | متن، رابط، مقایسه |
| روش پرداخت | درگاه، کارت‌به‌کارت، پرداخت در محل و اقساط فقط اگر پشتیبانی و شرایطشان معلوم است؛ رسید تأیید نهایی نیست. | متن، مقایسه، پژوهش |
| موبایل ایران | قالب توافق‌شدهٔ 09 و +98، حفظ صفر اولیه، ارقام فارسی/عربی/لاتین و قواعد واقعی سرور؛ شکل شماره مالکیت را ثابت نمی‌کند. | رابط، متن، مقایسه |
| ورود پیامکی | کد رشته است؛ زمان انقضا و ارسال مجدد واقعی باشد، خطای کد نادرست با تأخیر پیامک یکی نیست. | رابط، متن، مقایسه، پژوهش |
| تاریخ شمسی | نمایش انتخاب‌شدهٔ شمسی و Asia/Tehran؛ تاریخ فقط‌روز با لحظهٔ UTC اشتباه نشود. | رابط، متن، سئو |
| نشانی و ارسال | استان، شهر، محدوده، پلاک، واحد و کد پستی طبق نیاز ارسال؛ نشانی با تغییر شهر از دست نرود. | رابط، متن، مقایسه، پژوهش، سئو |
| نام و هویت | املای اصلی نام حفظ شود؛ یکسان‌سازی ی/ي و ک/ك برای کلید جست‌وجوی جدا، نه تغییر متن اصلی. | رابط، متن |
| راست‌به‌چپ | جهت معنایی، شناسه و URL لاتین، ترتیب خواندن و فوکوس، ورودی و کپی‌کردن بررسی شود. | رابط، مقایسه، سئو |
| زبان طبیعی | لحن برند و مخاطب واقعی، نیم‌فاصله و فعل روشن؛ صمیمیت یا رسمیت یک حکم ملی نیست. | متن، پژوهش، سئو |
| قطع اینترنت | فرم و سفارش حفظ شود؛ وضعیت نامشخص و پیشگیری از ثبت/پرداخت تکراری با قرارداد محصول بررسی شود. | رابط، متن، مقایسه، پژوهش |
| اعتماد و پشتیبانی | هویت فروشنده، تماس، شرایط و مسیر پیگیری قابل بررسی؛ لوگو تضمین کیفیت نیست. | متن، مقایسه، پژوهش، سئو |
| مناسبت و تعطیلی | نوروز/یلدا، سال، آخرین مهلت واقعی ارسال و پشتیبانی؛ تعطیلی و افزایش تقاضا حدس زده نشود. | متن، پژوهش، سئو |
| جست‌وجوی محلی | عبارت و شهر/محله با دادهٔ واقعی؛ صفحهٔ شهر بدون خدمت و صفحات تکراری املا نسازید. | سئو، پژوهش |

## مثال مبلغ

قرارداد ساختگی: مبلغ کالا ۲۵۰٬۰۰۰ تومان، ارسال ۳۰٬۰۰۰ تومان، ذخیرهٔ مبلغ به ریال.

- نمایش: «مبلغ قابل پرداخت: ۲۸۰٬۰۰۰ تومان».
- مبلغ ذخیره/درگاهِ ریالی: `2800000 IRR`، با تطبیق مستندات نسخهٔ انتخاب‌شده.
- اگر درگاه/SDK تومان می‌گیرد یا خودش تبدیل می‌کند، از تبدیل دوباره جلوگیری کنید؛ پیش‌فرض یک درگاه را به همه تعمیم ندهید.
- برای سکیما با واحد IRR، مقدار ریالی بگذارید؛ توکن IRT در یک API، مجوز استفاده از آن به‌عنوان کد عمومی ISO نیست.
- برای مبلغ ریالیِ غیرقابل تقسیم بر ۱۰، سیاست کسر تومان/گردکردن لازم است؛ کاهش خاموش مبلغ مجاز نیست.
