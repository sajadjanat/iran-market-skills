# اسکیل‌های بازار ایران و محصولات فارسی

[English](README.md) · [مجوز MIT](LICENSE) · [راهنماها و مثال‌ها](docs/README.md) · [معرفی و نمونه‌ها در سپهرا](https://sepehra.ir/skills/)

پنج اسکیل برای پژوهش بازار ایران و ساخت محصول فارسی: تصمیم پژوهشی، مقایسهٔ محصول، اصلاح رابط RTL، نگارش فارسی و بررسی سئو. هر خروجی شواهد، فرضیات و بررسی‌های انجام‌نشده را مشخص می‌کند.

## یک کاربرد ملموس

یک فرم فارسی ممکن است ظاهر مناسبی داشته باشد، اما شناسهٔ لاتین، شمارهٔ تماس یا برچسب فیلدهایش مشکل داشته باشند. اسکیل RTL این موارد را بررسی می‌کند.

صفحه‌های [قبل](examples/rtl/before.html) و [بعد](examples/rtl/after.html) یک مثال ساختگی و تألیفی‌اند. [راهنمای RTL](docs/persian-rtl-ux.md) نوع اصلاح و محدودیت بررسی را توضیح می‌دهد؛ این نمونه ادعای افزایش فروش ندارد.

برای Claude Code، Codex و ایجنت‌های پشتیبان قالب اسکیل قابل نصب است. برای Claude وب و دسکتاپ، ZIP مستقل هر اسکیل آماده است؛ [روش‌های نصب](docs/installation.md#claude-code) و [نمونه‌های قبل و بعد در سپهرا](https://sepehra.ir/skills/#examples) را ببینید.

## قواعد متناسب با ایران

[نقشهٔ ۱۶ موضوع کاربردی](docs/iran-context.fa.md): ریال و تومان و مبلغ نهایی، پرداخت و پیگیری وجه، موبایل و پیامک، تاریخ شمسی، نشانی و محدودهٔ ارسال، RTL، اعتماد و جست‌وجوی محلی. قواعد مرتبط داخل مرجع مستقل هر اسکیل هستند؛ سیاست بانک/درگاه و رفتار مخاطب حدس زده نمی‌شود.

برای تولید محتوا، [راهنمای بهبود مقالهٔ فارسی](docs/editorial-lessons.fa.md) را ببین: متن منسجم، مثال عملی، حفظ لحن تأییدشده و تصمیم محتوایی با دادهٔ موجود پروژه.

## نصب

با Node.js و Git و با توجه به نسخهٔ موردنیاز CLI:

```bash
npx skills@latest add sajadjanat/iran-market-skills
```

### نصب بستهٔ کامل پنج اسکیل

با یک دستور هر پنج اسکیل را نصب کن و ابزار خودت را از فهرست انتخاب کن:

```bash
npx skills@latest add sajadjanat/iran-market-skills --skill '*'
```

برای انتخاب مستقیم ابزار، `--agent claude-code`، `--agent codex` یا
`--agent cursor` را به دستور اضافه کن. در صورت نیاز، گفت‌وگو یا تسک تازه باز کن.

**Claude وب و دسکتاپ:** [بستهٔ کامل را دانلود کن](https://sepehra.ir/skills/downloads/iran-market-skills-bundle.zip).
فایل بسته را باز کن؛ پنج ZIP داخل آن را یکی‌یکی در Customize → Skills بارگذاری
و فعال کن. خود فایل بسته برای بارگذاری مستقیم یک اسکیل نیست.
[راهنمای نصب](https://sepehra.ir/skills/#install) و
[مراحل بارگذاری](docs/installation.md#claude-webdesktop-claudeai) را ببین.
بارگذاری در حساب Claude هنوز مستقل آزموده نشده است.

### نصب تکی

مشاهدهٔ فهرست و نصب یک اسکیل برای Codex:

```bash
npx skills@latest add sajadjanat/iran-market-skills --list
npx skills@latest add sajadjanat/iran-market-skills --skill persian-rtl-ux --agent codex
```

در صورت نیاز برای شناسایی اسکیل‌ها یک تسک تازه باز کن. [راهنمای نصب](docs/installation.md) روش بومی Codex، ویندوز، به‌روزرسانی و نصب محلی را دارد. هر اسکیل همراه مراجع، سیاست شواهد و مجوز خودش نصب می‌شود.

## اولین درخواست

```text
با $persian-rtl-ux این فرم فارسی را بررسی کن.
متن ترکیبی، شمارهٔ تماس، برچسب‌ها و چیدمان واکنش‌گرا را بررسی کن.
شناسه‌های ذخیره‌شده را تغییر نده و بگو کدام بررسی واقعاً اجرا شده است.
```

برای مثال آماده، فایل examples/rtl/before.html را بده. بررسی کد بدون مرورگر، تأیید رفتار واقعی صفحه نیست.

## شواهد و محدودیت

منابع متغیر باید هنگام استفاده دوباره بررسی شوند. آمار عمومی، مشاهده، دادهٔ کاربر و فرضیه یکی نیستند. نبود اینترنت، ورود، دادهٔ خصوصی یا محیط اجرا باید در خروجی مشخص شود.

[گزارش منابع در ۳ اکتبر ۲۰۲۶](research/source-review-2026-10-03.md) وضعیت واقعی دسترسی، از جمله منابع غیرقابل خواندن، را ثبت می‌کند. [سیاست داده](DATA-POLICY.md) مرز شواهد و انتشار را توضیح می‌دهد. [یادداشت پایلوت](research/iran-public-sources-pilot.md) سابقهٔ پژوهش است.

## بررسی کیفیت

قالب اصلی مطابق [Agent Skills](https://agentskills.io/specification) است؛ فایل openai.yaml اطلاعات نمایش Codex را دارد. شناسایی پنج اسکیل توسط CLI به‌تنهایی سازگاری اجرایی همهٔ ایجنت‌ها را ثابت نمی‌کند.

```bash
python -m pip install -r requirements-dev.txt
python scripts/validate_repo.py
python -m unittest discover -s tests -v
```

این بررسی‌ها ساختار و بسته‌بندی را می‌سنجند. [سناریوهای ارزیابی](evals/README.md) برای سنجش خروجی واقعی‌اند و نیاز به اجرا و ثبت نتیجه دارند.

نسخهٔ 0.2.0 کاندید انتشار است؛ وضعیت انتشار در [تغییرات](CHANGELOG.md) ثبت می‌شود. [نتایج واقعی بررسی](evals/results/review-2026-10-03.md) نصب، سناریوها، مرورگر و CI را ثبت می‌کند. manifest پلاگین به معنی انتشار در مارکت‌پلیس نیست. [مشارکت](CONTRIBUTING.md)، [انتشار و نگهداری](docs/releasing.md) و [مجوز MIT](LICENSE) را ببین؛ منابع شخص ثالث مجوز خودشان را دارند.

زبان فارسی و بازار ایران دو ورودی جدا هستند. [بررسی کاربرد در ایران و فارسی](research/iran-context-review-2026-10-03.md) مبنای تکمیل تحقیق مشتری، پیام‌های پرداخت، قرارداد ورودی ارقام و صفحات محلی/مناسبتی است؛ تناسب توصیه‌ها با مخاطب واقعی همچنان باید با تحقیق کاربر سنجیده شود.

برای آزمون با مخاطب واقعی، [راهنمای سنجش کاربرد](docs/user-validation.fa.md) کارها و شواهد قابل ثبت را مشخص می‌کند؛ چنین تحقیق مشتری‌ای هنوز در این ریپو انجام نشده است.

[پنج ارزیابی مستقلِ کاربرد محلی](evals/results/iran-context-2026-10-03/review.md) هر ۲۲ معیار را گذراندند؛ ورودی‌ها ساختگی‌اند و این نتیجه تحقیق با مشتری واقعی نیست.
