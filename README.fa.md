# اسکیل‌های بازار ایران و محصولات فارسی

[English](README.md) · [مجوز MIT](LICENSE) · [راهنماها و مثال‌ها](docs/README.md)

پنج اسکیل برای پژوهش بازار ایران و ساخت محصول فارسی: تصمیم پژوهشی، مقایسهٔ محصول، اصلاح رابط RTL، نگارش فارسی و بررسی سئو. هر خروجی شواهد، فرضیات و بررسی‌های انجام‌نشده را مشخص می‌کند.

## یک کاربرد ملموس

یک فرم فارسی ممکن است ظاهر مناسبی داشته باشد، اما شناسهٔ لاتین، شمارهٔ تماس یا برچسب فیلدهایش مشکل داشته باشند. اسکیل RTL این موارد را بررسی می‌کند.

صفحه‌های [قبل](examples/rtl/before.html) و [بعد](examples/rtl/after.html) یک مثال ساختگی و تألیفی‌اند. [راهنمای RTL](docs/persian-rtl-ux.md) نوع اصلاح و محدودیت بررسی را توضیح می‌دهد؛ این نمونه ادعای افزایش فروش ندارد.

## نصب

با Node.js و Git و با توجه به نسخهٔ موردنیاز CLI:

```bash
npx skills@latest add sajadjanat/iran-market-skills
```

در نصب، اسکیل‌ها و ایجنت را انتخاب کن. مشاهدهٔ فهرست و نصب یک اسکیل برای Codex:

```bash
npx skills@latest add sajadjanat/iran-market-skills --list
npx skills@latest add sajadjanat/iran-market-skills --skill persian-rtl-ux --agent codex
```

در صورت نیاز برای شناسایی اسکیل‌ها یک تسک تازه باز کن. [راهنمای نصب](docs/installation.md) روش بومی Codex، ویندوز، به‌روزرسانی و نصب محلی را دارد. هر اسکیل همراه مراجع، سیاست شواهد و مجوز خودش نصب می‌شود.

## اولین درخواست

```text
با $persian-rtl-ux این فرم فارسی را بررسی کن.
متن ترکیبی، شمارهٔ تماس، برچسب‌ها و چیدمان واکنش‌گرا را بررسی کن.
شناسه‌های ذخیره‌شده را تغییر نده و بگو کدام بررسی واقعاً اجرا شده است.
```

برای مثال آماده، فایل examples/rtl/before.html را بده. بررسی کد بدون مرورگر، تأیید رفتار واقعی صفحه نیست.

## انتخاب اسکیل

| اسکیل | کاربرد | خروجی و راهنما |
|---|---|---|
| iran-market-discovery | انتخاب بخش مشتری یا فرصت پژوهش بازار | شواهد و آزمایش بعدی · [راهنما](docs/iran-market-discovery.md) |
| iran-product-benchmark | مقایسهٔ جریان محصولات ایرانی | مشاهدهٔ تاریخ‌دار و پیشنهاد طراحی · [راهنما](docs/iran-product-benchmark.md) |
| persian-rtl-ux | ساخت یا بررسی رابط فارسی و متن ترکیبی | گزارش یا اصلاح همراه وضعیت آزمون · [راهنما](docs/persian-rtl-ux.md) |
| persian-brand-copy | نگارش فارسی متناسب با پیشنهاد و مخاطب | متن قابل استفاده با ادعاهای بررسی‌شده · [راهنما](docs/persian-brand-copy.md) |
| persian-seo | اولویت‌بندی بهبود صفحات فارسی | یافته‌های صفحه‌محور و برنامهٔ سنجش · [راهنما](docs/persian-seo.md) |

هر اسکیل مستقل است. در کار بزرگ‌تر می‌توان از پژوهش به مقایسه، سپس UX/متن و در صورت نیاز سئو رفت؛ اجرای یکی وابسته به نصب بقیه نیست.

## شواهد و محدودیت

منابع متغیر باید هنگام استفاده دوباره بررسی شوند. آمار عمومی، مشاهده، دادهٔ کاربر و فرضیه یکی نیستند. نبود اینترنت، ورود، دادهٔ خصوصی یا محیط اجرا باید در خروجی مشخص شود.

[گزارش منابع در ۳ اکتبر ۲۰۲۶](research/source-review-2026-10-03.md) وضعیت واقعی دسترسی، از جمله منابع غیرقابل خواندن، را ثبت می‌کند. [سیاست داده](DATA-POLICY.md) مرز شواهد و انتشار را توضیح می‌دهد. [یادداشت پایلوت](research/iran-public-sources-pilot.md) سابقهٔ پژوهش است.

## بررسی کیفیت

قالب اصلی مطابق [Agent Skills](https://agentskills.io/specification) است؛ فایل openai.yaml اطلاعات نمایش Codex را دارد. شناسایی پنج اسکیل توسط CLI به‌تنهایی سازگاری اجرایی همهٔ ایجنت‌ها را ثابت نمی‌کند.

```bash
python -m pip install -r requirements-dev.txt
python scripts/validate_repo.py
python -m unittest discover -s tests -v
```

این بررسی‌ها ساختار و بسته‌بندی را می‌سنجند. [سناریوهای ارزیابی](evals/README.md) برای سنجش خروجی واقعی‌اند و نیاز به اجرا و ثبت نتیجه دارند.

نسخهٔ 0.2.0 در فایل‌ها آماده می‌شود؛ وضعیت انتشار در [تغییرات](CHANGELOG.md) ثبت می‌شود. manifest پلاگین به معنی انتشار در مارکت‌پلیس نیست. [مشارکت](CONTRIBUTING.md)، [انتشار و نگهداری](docs/releasing.md) و [مجوز MIT](LICENSE) را ببین؛ منابع شخص ثالث مجوز خودشان را دارند.
